Getting Started with YAGSL
============================

Follow this guide to get started with YAGSL. YAGSL is a Java library that allows you to program your robot using a simple and easy-to-understand syntax. We are going to copy the example program and use that as our starting point.

.. tip:: 

    * In VS Code, you can use the `Ctrl + Shift + P` shortcut to open the command palette and search for commands. This is a great way to quickly access features and functions in VS Code.
    * Select the `Git: Clone` command and paste the URL of the repository you want to clone. This will create a local copy of the repository on your machine.
    * The URL we are using is `https://github.com/Yet-Another-Software-Suite/YAGSL-Example.git <https://github.com/Yet-Another-Software-Suite/YAGSL-Example.git>`_.
