YAGSL Configuration Files
=========================

Now that you have the initial sample code, we need to configure the YAGSL library to work with your robot. The configuration files are located in the `src/main/resources` directory of your project.

But, YAGSL provides a web-based configuration tool that makes it easy to generate the configuration files for your robot. You can access the `YAGSL configuration tool <https://config.yagsl.com/>`_.
