Getting Started with YAGSL
============================

Follow this guide to get started with YAGSL. YAGSL is a Java library that allows you to program your robot using a simple and easy-to-understand syntax.

.. tip:: 

    Open a new tab and go to the `YAGSL Getting Started Guide <https://config.yagsl.com/guide>`_.

.. admonition:: Try it out

    Copy the command2 folder contents to your new robot project. :code:`cp -r command2/* <your_project_name>` 


.. tip:: 
    
    Build your code to test if it compiles. If it does not compile, check the error messages and fix the issues. If you are having trouble, ask for help from your instructor or a mentor.
