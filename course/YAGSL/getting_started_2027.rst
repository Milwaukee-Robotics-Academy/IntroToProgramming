Getting Started with YAGSL
============================

Follow this guide to get started with YAGSL. YAGSL is a Java library that allows you to program your robot using a simple and easy-to-understand syntax. We are going to copy the example program and use that as our starting point.

Lets follow the tutorial provided by YAGSL. `https://yagsl.yassrobotics.com/get-started/tutorial <https://yagsl.yassrobotics.com/get-started/tutorial>`_.
Here are the individual steps to get started with YAGSL. We will be using the example code provided by YAGSL as our starting point.

Gather your Robot information
------------------------------
* We need to gather some information about our robot. This includes the type of robot we are using, the type of motors we are using, and the type of sensors we are using. This information will be used to configure YAGSL for our robot.
* We will use Last year's robot as our starting point. We will be using the same type of motors and sensors as last year. We will also be using the same type of robot as last year. The only differnce is, for Gyro, we will be using the Pigeon2 in ths example.
* The steps are listed here: `https://yagsl.yassrobotics.com/get-started/01-gather-your-robot-information <https://yagsl.yassrobotics.com/get-started/01-gather-your-robot-information>`_.

Generate your YAGSL configuration
------------------------------
* We need to generate a YAGSL configuration for our robot. This configuration will be used to configure YAGSL for our robot. We will use the information we gathered in the previous step to generate the configuration.
* The steps are listed here: `https://yagsl.yassrobotics.com/get-started/02-generate-your-yagsl-configuration <https://yagsl.yassrobotics.com/get-started/02-generate-your-yagsl-configuration>`_.

Install YAGSL
-------------
* We need to install YAGSL on our computer. This will be done using the WPILib vendor dependency manager.
* The steps are listed here: `https://yagsl.yassrobotics.com/get-started/03-install-yagsl <https://yagsl.yassrobotics.com/get-started/03-install-yagsl>`_.

Write The Code
----------------
* We need to write the code for our robot. We will use the example code provided by YAGSL as our starting point. We will copy the example code into our project and use that as our starting point.
* The steps are listed here: `https://yagsl.yassrobotics.com/get-started/04-write-the-code <https://yagsl.yassrobotics.com/get-started/04-write-the-code>`_.

Test The Code
----------------
* We will use the WPILib simulator to test our code. We will run the simulator and test our code to make sure it works as expected.
* Let's make sure we have Advantage Scope installed on our computer. We will use Advantage Scope to view the data from our robot and make sure everything is working as expected.
* First lets add our robot to the 2D Field in advantage Scope. Simply drag and drop the robot from the left side (Mechanisms/swerve/field/Robot)of the screen onto the Poses section under 2D Field tab.
* More information here: `https://yagsl.yassrobotics.com/get-started/05-test-the-code <https://yagsl.yassrobotics.com/get-started/05-test-the-code>`_.
