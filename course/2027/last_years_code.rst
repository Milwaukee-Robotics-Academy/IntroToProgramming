Last Year's Code
=================
Let's migrate your 2026 WPILib code to 2027 WPILib. 


Open your 2026 robot project in VSCode
--------------------------------------

* Clone last years code in VS code. Last years code is here:  `https://github.com/Milwaukee-Robotics-Academy/2026 <https://github.com/Milwaukee-Robotics-Academy/2026>`_.
.. tip:: 

    To clone the repo, open VSCode and select `View > Command Palette` and type `Git: Clone`. Paste the URL above and select a folder to clone the repo into. You can also use the terminal to clone the repo using the command `git clone <repo-url>`.

* Use the `git checkout <your-team-number>` command to switch to your personal branch. This is important because it allows you to work on your own code without affecting the main branch. If you are not sure how to do this, ask for help from your instructor or a mentor.

.. tip::

    You can also select the branch from the bottom left corner of VSCode. Click on the branch name and select your personal branch from the list.
