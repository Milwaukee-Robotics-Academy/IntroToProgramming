Environment Setup
==============

Here are some things we recommend you do to get your environment set up for the course.

Site access needs for the network:

* Access to `Milwaukee Robotics Academy <https://milwaukeeroboticsacademy.org/>`_ website for course materials and resources.
* Access to `YAGSL configuration tool <https://config.yagsl.com/>`_ for generating configuration files for your robot.
* Access to `GitHub repositories <https://github.com/>`_ for version control and collaboration on your robot code.
* Access to `WPILib documentation <https://docs.wpilib.org/>`_ for reference and guidance on using WPILib.
* Access to `Read The Docs Site <https://readthedocs.io/>`_ for understanding the rules and requirements of the FRC game.
* Access to `FRC Control System <https://docs.wpilib.org/en/stable/docs/software/overview/control-system.html>`_ for understanding the components and architecture of the FRC control system.
* Access to `FRC Community <https://frc-community.org/>`_ for connecting with other FRC teams and sharing knowledge.
* Access to `FRC Discord <https://discord.gg/frc>`_ for real-time communication and support from the FRC community.
* Access to `FRC YouTube Channel <https://www.youtube.com/user/FIRSTRobotics>`_ for watching tutorials and updates.
* Access to `FRC Design <https://frcdesign.org>`_ CAD training
* Access to `Onshape <https://onshape.com>`_ for CAD design and collaboration.
