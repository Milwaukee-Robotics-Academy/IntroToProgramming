Getting Help
============

When you run into compiler errors, YAGSL configuration questions, or Systemcore/WPILib 2027 behavior you do not expect, use these resources in order:

1. **Read the Compiler / Driver Station Output**: Note the exact file name, line number, and error message before asking for help.
2. **Ask Your MRA Instructor or Mentor**: Share your branch name and the error message so mentors can pull your code and debug with you.
3. **Official Documentation**:

   * `WPILib Documentation <https://docs.wpilib.org/>`_
   * `WPILib 2027 Yearly Changelog <https://docs.wpilib.org/en/2027/docs/yearly-overview/yearly-changelog.html>`_
   * `YAGSL Documentation <https://yagsl.yassrobotics.com/>`_

4. **FRC Community Channels**:

   * `Chief Delphi <https://www.chiefdelphi.com/>`_
   * `FRC Discord <https://discord.gg/frc>`_
   * `FRC Community <https://frc-community.org/>`_
