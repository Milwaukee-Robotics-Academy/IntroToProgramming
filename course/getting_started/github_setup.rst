GitHub & Organization Setup
===========================

We use GitHub to store robot code, track changes, and collaborate across teams.

1. Create or Sign In to GitHub
------------------------------

1. Open `GitHub <https://github.com/>`_ in a new tab.
2. Sign in to your existing GitHub account, or select **Sign up** to create a new account.

2. Join the MRA Organization
----------------------------

Once you are signed in to GitHub:

1. Share your **GitHub username** with your instructor.
2. Your instructor will send you an invitation to join the **Milwaukee Robotics Academy (MRA)** GitHub organization.
3. Accept the invitation from your email or the banner at the top of GitHub.

3. Switching GitHub Accounts in VS Code
---------------------------------------

If you are using a shared lab laptop, another student may already be signed in to GitHub inside VS Code. Before committing or pushing code, verify you are signed in with **your** account.

.. youtube:: pMd6LhfW6Hw

.. tip::

   If Windows keeps signing you in with the wrong GitHub account when pushing code, clear the stored credentials:

   1. Open **Control Panel** -> **User Accounts** -> **Credential Manager** -> **Windows Credentials**.
   2. Remove any saved entries related to ``github.com``.
   3. Sign back in to GitHub from VS Code.
