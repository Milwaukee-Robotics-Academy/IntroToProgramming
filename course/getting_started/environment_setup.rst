Environment Setup
=================

Follow this checklist to make sure your computer and network are ready for FRC 2027 software development with WPILib, Systemcore, and YAGSL.

Required Software
-----------------

1. **WPILib 2027 (for Systemcore)** — Provides the FRC Java libraries, VS Code distribution, Gradle build system, and Robot Simulator.

   * If you have not run the MRA installation scripts, follow the official `WPILib Installation Guide <https://docs.wpilib.org/en/latest/docs/zero-to-robot/step-2/wpilib-setup.html>`_.

2. **AdvantageScope** — Modern log viewer and 2D/3D field visualization tool used to inspect telemetry and simulate swerve drive behavior.
3. **Git** — Version control used alongside VS Code and GitHub.

.. tip::

   After installing WPILib, verify your installation by opening WPILib VS Code and running a test build (``Ctrl + Shift + P`` -> ``WPILib: Build Robot Code``). If the build fails, read the compiler error output first, then ask an instructor or mentor for help.

Network & Website Access
------------------------

If you are working on a school or managed laptop, make sure your network allows access to the following sites:

* `Milwaukee Robotics Academy <https://milwaukeeroboticsacademy.org/>`_ — Course materials and team programs.
* `Read the Docs <https://readthedocs.io/>`_ — Hosting platform for this curriculum and WPILib documentation.
* `GitHub <https://github.com/>`_ — Source control and team code collaboration.
* `WPILib Documentation <https://docs.wpilib.org/>`_ — Official reference for WPILib Java APIs and tools.
* `FRC Control System Overview <https://docs.wpilib.org/en/stable/docs/software/overview/control-system.html>`_ — Architecture of the FRC control system.
* `YAGSL Documentation <https://yagsl.yassrobotics.com/>`_ and `YAGSL Configuration Tool <https://config.yagsl.com/>`_ — Generating and configuring swerve drive files.
* `FRC Community <https://frc-community.org/>`_, `FRC Discord <https://discord.gg/frc>`_, and `FIRST Robotics YouTube <https://www.youtube.com/user/FIRSTRobotics>`_ — Community tutorials and support.
* `FRC Design <https://frcdesign.org>`_ and `Onshape <https://onshape.com>`_ — Optional CAD reference and collaboration tools.
