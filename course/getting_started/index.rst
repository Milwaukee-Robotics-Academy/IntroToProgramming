Getting Started
===============

Before writing robot code for the 2027 season, set up your development environment, connect your GitHub account to Milwaukee Robotics Academy (MRA), and verify your VS Code + Git workflow.

Module Objectives
-----------------

By the end of this module, you will be able to:

* Verify network access and install the WPILib 2027 toolchain and AdvantageScope.
* Create or sign in to your GitHub account and join the MRA GitHub organization.
* Clone a repository, switch branches, and manage GitHub accounts in VS Code.
